=== 待你确认/注意的两项 ===

1) Modrinth 项目目前不可公开访问：api.modrinth.com/v2/project/mtk2daDL 返回 404，
   而同一次实测中对照项目（sodium、fabric-api）正常返回，说明该项目已上传但仍在
   Modrinth 审核队列中，未公开。站点会校验「相关链接」里的地址能否正常访问，
   所以在 Modrinth 页面可访问之前，先不要填 Modrinth 链接（先只填 CurseForge
   与 GitHub）；等审核通过后再编辑条目补上。

   Modrinth Project ID 字段可以先填 mtk2daDL（那是项目 ID，不是链接）。

2) CurseForge 链接的 slug：暂按项目名记为 bedrock-allow-deny-border，
   但本机访问 curseforge.com 被 Cloudflare 拦截、v1 API 需要 key，无法核实。
   请打开 CurseForge 项目页，把地址栏里的 URL 发我，或自行填对。

=== 提交步骤 ===

1. 登录 mcmod.cn（无账号则先注册），打开 https://www.mcmod.cn/class/add/
2. 按上表填字段；正文先在编辑器里点「清除格式」，再粘贴
   docs/mcmod-description.md 的内容。
3. 上传封面 docs/mcmod-cover-720x450.png。
4. 填写改动说明、输入人机验证码，提交。
5. 在 https://www.mcmod.cn/verify/ 查看审核状态。
   站点规则：提交满 24 小时后可以催审，之后每隔 1 小时可再催一次。
   若你的用户组有免审权限，编辑器顶部会提示。
6. 审核通过后把条目 URL 发我，我核对「支持平台 / 运作方式 / 模组元素 /
   支持MC版本 / 运行环境 / 开源状态 / CFID / MRID」是否与本地记录一致。
